# Операционный журнал MIKISSKIDS

Этот файл ведётся как append-only журнал важных действий.

Правило работы:

1. Перед новым блоком обновить `STATUS.md`.
2. После изменения архитектуры обновить `DECISIONS.md`.
3. После завершения блока обновить `TODO.md`.
4. После production-действия добавить запись ниже.
5. Не записывать секреты, пароли, токены и персональные данные покупателей.
