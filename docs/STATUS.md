## Платёжный MVP

Принято решение не писать собственную интеграцию с Т-Банком.

Текущая схема:

```text
основной сайт на VPS
        ↓
pay.mikisskids.ru на Tilda
        ↓
корзина ST100
        ↓
готовый модуль Tilda → Т-Банк
        ↓
стандартная страница результата Т-Банка
```

На Tilda опубликована тестовая страница:

- `http://mikisskids.ru/payment-mvp`;
- временная страница успеха:
  `http://mikisskids.ru/payment-success`.

Проверено:

- обе карточки открывают форму ST100;
- стульчик передаётся с ценой 35 000 ₽;
- чемодан передаётся с ценой 50 000 ₽;
- после формы открывается защищённая страница Т-Банка;
- после выхода товар очищается, пустая корзина не показывается.

Собственная страница успеха для MVP не обязательна. Используется
стандартный результат Т-Банка.

## Важное ограничение перед переносом домена

После направления `mikisskids.ru` на VPS текущие Tilda-адреса
`/payment-mvp` и `/payment-success` перестанут открываться.

До переключения DNS необходимо:

1. Подключить `pay.mikisskids.ru` к проекту Tilda.
2. Выпустить SSL на стороне Tilda.
3. Проверить `https://pay.mikisskids.ru/payment-mvp`.
4. Заменить кнопки основного сайта на этот адрес.
5. Только после этого переносить основной домен на VPS.

## Текущее поведение кнопок основного сайта

Кнопки «Оформить заказ» в репозитории пока открывают локальный
прототипный `<dialog>`. Форма не отправляет данные и не открывает Tilda.

До production необходимо заменить это поведение переходом на:

```text
https://pay.mikisskids.ru/payment-mvp
```

До готовности поддомена существующее поведение не менять.

## Следующий блок

Создать минимальный приёмник Tilda Webhook на VPS:

- приём `application/x-www-form-urlencoded`;
- идемпотентность по `tranid`;

- systemd unit;
- Nginx proxy;
- резервное копирование БД;
- тестирование повторного webhook.

Webhook подключается к ST100. В настройках платёжной системы Tilda
должна оставаться отправка данных только после оплаты.
