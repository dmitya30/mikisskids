## Платёжный контур

Используется схема:

```text
основной сайт на VPS
        ↓
pay.mikisskids.ru на Tilda
        ↓
корзина ST100
        ↓
готовый модуль Tilda → Т-Банк
        ↓
Tilda webhook после оплаты
        ↓
SQLite на VPS
```

Платёжные страницы доступны по HTTPS:

- `https://pay.mikisskids.ru/`;
- `https://pay.mikisskids.ru/payment-mvp`;
- `https://pay.mikisskids.ru/success_payment`;
- `https://pay.mikisskids.ru/payment-success`.

На Tilda:

- используются два основных товара;
- используется корзина ST100;
- подключён готовый модуль Tilda → Т-Банк;
- webhook отправляется только после оплаты;
- cookies и JSON в webhook отключены;
- API METHOD оставлен `Off`;
- общий consent-модуль подключён через HEAD-код проекта;
- встроенные интеграции Яндекс Метрики и Mail.ru/VK отключены;
- legacy-счётчики `107009480` и `3752851` удалены;
- обе success-страницы имеют универсальный текст и
  `noindex, nofollow`.

По информации владельца:

- терминал рабочий и активный;
- используется одностадийная оплата;
- подключён CloudKassir;
- применяется УСН «Доходы» 6%;
- заявлена ставка НДС 5%.

Эти параметры ещё не подтверждены полным контрольным платежом,
кассовым чеком и возвратом. Платёжные настройки и доступ к Т-Бизнесу
владелец проекта проверяет самостоятельно.

## Техническое SEO

В production развёрнуто:

- canonical для 5 основных страниц;
- Open Graph и Twitter Card для 5 основных страниц;
- `sitemap.xml` с 5 индексируемыми URL;
- ссылка на sitemap в `robots.txt`;
- `noindex, follow` и canonical для 4 legal-страниц;
- Organization и WebSite JSON-LD на главной;
- Product и Offer JSON-LD на страницах двух товаров;
- JSON-LD проверен через Google Rich Results Test в режиме кода,
  Schema.org Validator и валидатор Яндекса;
- внешние валидаторы не обнаружили ошибок;
- собственная страница 404;
- Nginx возвращает кастомную страницу с HTTP 404;
- прямой запрос `/404.html` также возвращает HTTP 404;
- всем HTML-изображениям и видео добавлены реальные `width` и `height`;
- изображения, создаваемые через `js/main.js`, также получили размеры;
- три hero-изображения используют `fetchpriority="high"` без lazy loading;
- lazy loading сохранён для изображений ниже первого экрана;
- автоматический SEO-аудит проверяет размеры медиа и приоритет hero;
- оба товарных MP4 переведены в Fast Start без перекодирования;
- production-видео поддерживают HTTP Range с кодом 206.

Индексация пока намеренно закрыта:

```text
User-agent: *
Disallow: /
```

До открытия индексации остаются:

- проверка Core Web Vitals;
- завершение настройки целей Метрики;
- добавление сайта в Яндекс Вебмастер;
- контрольный платёж, чек, webhook и возврат;
- финальный production-аудит;
- снятие `Disallow: /`.

Конвертация текущих JPEG в WebP/AVIF не является приоритетной:
самое крупное изображение занимает около 245,5 KiB. Основной тяжёлый
медиаресурс сайта — видео; для обоих MP4 уже включён Fast Start без
изменения сжатых медиапотоков.

## Аналитика

Счётчик Яндекс Метрики `111056887` установлен:

- на основном сайте `mikisskids.ru`;
- на платёжном поддомене `pay.mikisskids.ru`;
- только через единый consent-модуль;
- без Вебвизора;
- с сохранением выбора в cookie `mk_cookie_consent`
  для домена `.mikisskids.ru`.

Проверены сценарии:

- до согласия код Метрики не загружается;
- отказ сохраняется и не блокирует оформление заказа;
- выбор действует при переходах между основным доменом и `pay`;
- после согласия загружается только счётчик `111056887`;
- пользователь может изменить решение через «Настройки cookies».

С Tilda удалены ранее установленные legacy-счётчики:

- Яндекс Метрика `107009480`;
- Top.Mail.Ru / VK Pixel `3752851`.

Для двух возможных страниц возврата после оплаты созданы раздельные
диагностические URL-цели:

- `/success_payment`;
- `/payment-success`.

Открытие success-страницы не считается надёжным подтверждением оплаты.
Фактический Return URL и подтверждённую оплату необходимо проверить
после получения доступа к Т-Бизнесу и проведения контрольного платежа.

Остальные цели Метрики будут настроены одним блоком после проверки
полной воронки.
