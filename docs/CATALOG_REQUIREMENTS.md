# Требования к каталогу

**Статус:** draft  
**Дата:** 03.08.2026

## Master data товара

Для каждого товара нужны:

- internal ID;
- SKU;
- название;
- категория;
- краткое и полное описание;
- варианты;
- цвет;
- цена по рынкам;
- валюта;
- остаток;
- статус наличия;
- дата поступления;
- вес и размеры товара;
- вес и размеры упаковки;
- материалы;
- страна происхождения;
- HS code;
- комплектация;
- возраст;
- ограничения нагрузки;
- уход;
- гарантия;
- инструкции;
- предупреждения;
- фотографии;
- видео;
- сертификаты и test reports;
- данные производителя и импортёра.

## Российский каталог

Минимальные URL:

```text
/catalog/
/catalog/<category>/
/<product-slug>/
```

Для текущих товаров сохраняются:

```text
/chair/
/travel-seat/
```

Необходимость новых URL и редиректов определяется после получения
полного ассортимента.

## Карточка товара

- hero;
- цена;
- наличие;
- варианты;
- галерея;
- benefits;
- configurations;
- specifications;
- package contents;
- instructions;
- safety limitations;
- delivery;
- returns;
- warranty;
- FAQ;
- related products;
- CTA.

Отзывы публикуются только при наличии реальных подтверждённых отзывов.

## Запрет расхождений

Цена, наличие, дата поступления, SKU и варианты не должны вручную
расходиться между:

- VPS storefront;
- Tilda;
- международным storefront;
- structured data;
- sitemap и feed.

Перед разработкой необходимо определить единый источник master data.
