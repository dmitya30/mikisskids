## Задача

Создать компактный интернет-магазин MIKISSKIDS для двух флагманских
товаров:

1. Стульчик-трансформер.
2. Чемодан-кресло для семейных путешествий.

Каждый товар получает отдельную страницу для целевого рекламного трафика.

Сайт должен передавать качество, комфорт и спокойный характер бренда через
фотографии, детали изделий, ясный текст и аккуратный интерфейс.

## Аудитория и язык

Тексты предназначены для обеспеченных семей, которые обращают внимание
на дизайн, качество исполнения, удобство и обслуживание.

Правила копирайтинга:

- говорить простым и естественным языком;
- не использовать профессиональный жаргон производителя и маркетолога;
- не называть продукт «премиальным» - это должно считываться из подачи;
- не строить коммуникацию вокруг страхов и «болей»;
- не использовать давление, таймеры, искусственный дефицит;
- не публиковать неподтверждённые заявления;
- не обещать абсолютную безопасность;
- не использовать выражения «инновационный», «уникальное решение»,
  «лучший на рынке» и подобные без доказательств.

## Правила Git

- файлы создаются и изменяются через `cat > file << 'EOF'`;
- секреты и приватные данные не коммитятся;
- медиа добавляются только из согласованных папок;
- один логический этап - один понятный коммит;
- перед коммитом выполняется проверка `git diff`;
- перед push проверяется отсутствие приватного адреса и платёжных секретов.
